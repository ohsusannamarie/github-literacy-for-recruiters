# Community Recruiting Library

Welcome to the experiment inside the experiment.

This folder is a small community-curated library designed to demonstrate how GitHub can be useful even when nobody is writing software.

## The rules

This is **not** an ebook dump.

Only add resources that can legitimately be shared here or linked to publicly, such as:

- Official documentation
- Open educational resources
- Public research and reports
- Publicly available guides
- Open-source tools
- Resources published by their creators for free access
- Links to books, courses, or paid resources on their legitimate publisher or creator pages

Do **not** upload copyrighted books, paywalled reports, pirated PDFs, leaked internal documents, or other material you do not have permission to redistribute.

## Your first contribution

Found something that belongs here?

### Easiest route: request it

Open an **Issue** with:

```text
Resource name:
Creator / publisher:
URL:
Suggested shelf:
Why it is useful:
Why it is okay to share or link:
```

That teaches you how Issues work without requiring you to edit a file.

### Full GitHub route: contribute it yourself

1. Fork this repository.
2. Edit this file in your fork.
3. Add the resource to the appropriate shelf.
4. Commit your change with a useful message such as `Add GitHub sourcing resource`.
5. Open a pull request back to this repository.
6. Explain why the resource belongs in the collection.

Congratulations. You just used the same collaboration model that open-source software projects use, without writing a line of software.

## What to notice while you do this

Pay attention to the GitHub concepts happening around the content:

- Your fork knows which repository it came from.
- Your commit records exactly what changed.
- Your pull request shows the proposed difference between your version and the original.
- Discussion about your contribution stays attached to the proposed change.
- If the contribution is merged, GitHub records it as part of the project's history.
- Your GitHub profile can reflect your contribution to the project.

That machinery is the point of this exercise.
