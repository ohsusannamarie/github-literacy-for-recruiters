# What is GitHub?

GitHub is a platform for storing, organizing, changing, discussing, and collaborating on projects.

Software developers use it heavily because GitHub is built around **version control** - keeping track of how files change over time. But the basic ideas are useful far beyond programming.

## The recruiter mental model

Think of a GitHub repository as a project folder that can answer questions a normal folder usually cannot:

- What changed?
- When did it change?
- Who changed it?
- Why did they change it?
- What did the project look like before?
- What work is still open?
- Who else has contributed?
- Can I suggest a change without overwriting the original?

That is why a repository is more than a bucket of files.

## Why technical talent uses GitHub

People use GitHub to:

- build software
- contribute to open source
- publish tools and libraries
- document projects
- collaborate with coworkers
- experiment
- learn
- report problems
- review proposed changes
- maintain technical documentation
- share datasets, tutorials, templates, and research

A GitHub profile can therefore contain traces of **work**, not merely claims about work.

## Why recruiters should care

Recruiters often encounter GitHub only as a sourcing destination. That is like using LinkedIn while understanding profiles but not posts, companies, connections, or professional behavior.

Before interpreting someone's activity, understand the environment that produced it.

## What GitHub is NOT

GitHub is not:

- a complete resume
- a definitive measure of engineering ability
- proof that every visible repository was authored by the person
- proof that every listed programming language represents expertise
- a complete record of someone's professional work

Most company work is private. Many excellent engineers have sparse public profiles. Some highly active GitHub users are students, hobbyists, researchers, writers, designers, recruiters, or people working in adjacent technical fields.
